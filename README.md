# Birthday Gift Studio

A mobile-first interactive birthday microsite built with Next.js, Tailwind CSS v4, and Framer Motion.

## Features
- Animated gift-opening welcome screen
- Birthday wish moment
- Interactive cake candles
- Birthday mood quiz
- Memory cards
- Letter reveal and confetti finale

## Run locally
Requires Node.js 20+.

```bash
npm install
npm run dev
```

Open http://localhost:3000.

This is the frontend prototype. The sound control is visual-only and Supabase/authentication are not yet configured. Next milestones: creator dashboard, Supabase persistence, shareable birthday pages, and Vercel deployment.
